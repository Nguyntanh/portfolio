# Nguyễn Tuấn Anh - Technical Business Analyst Portfolio

Portfolio cá nhân chuyên sâu về **Technical Business Analysis**, **System Architecture**, **Data Modeling (3NF)** và **Process Optimization**.

## 📌 Tổng Quan Hệ Thống

Portfolio được thiết kế với chuẩn thẩm mỹ cao cấp, cấu trúc module tinh gọn và logic trình bày sắc bén gồm 5 phân hệ cốt lõi:

1. **Hero Section**: Huy hiệu chuyên môn, tuyên ngôn giá trị (Value Proposition), Dual CTA ("Khám Phá Case Studies" & "Tải Technical BA Resume (PDF)") và bộ 3 chỉ số đo lường năng lực phân tích & mô hình hóa hệ thống (0% Data Drift, 2 Enterprise Platforms, -58.5% Quãng đường nhặt hàng).
2. **Featured Technical Case Studies**: Đặc tả hệ thống, mô hình hóa dữ liệu 3NF, kiểm soát đồng thời và đo lường tác động (Google XYZ):
   - **Smart WMS** (Hệ thống quản lý kho hàng thông minh): Quy chuẩn hóa nghiệp vụ (SRS, 10 bất biến, Inbound/Put-away/Picking/Outbound), mô hình hóa không gian 3D kết hợp ma trận ABC và định tuyến S-Shape, toàn vẹn dữ liệu 18 bảng 3NF & khóa bi quan (SELECT ... FOR UPDATE) trên InnoDB triệt tiêu Race Condition.
   - **InternHub** (Nền tảng quản lý thực tập sinh tập trung): Chuẩn hóa 33 INVEST User Stories & 38 RESTful API Contracts (OpenAPI), bảo vệ toàn vẹn dữ liệu 26 bảng & Immutable JSONB Snapshots, xử lý nền BullMQ/Redis và chống Deadlock tuần tự hóa (ORDER BY mentor_id ASC).
3. **Năng lực Phân tích & Kỹ thuật Hệ thống (Technical BA Competencies)**: Bộ kỹ năng chuẩn hóa 4 trụ cột:
   - *Tầng 1*: Phân tích Nghiệp vụ & Mô hình hóa Quy trình (Business & Process Modeling)
   - *Tầng 2*: Dữ liệu & Xử lý Giao dịch (Data Architecture & Concurrency)
   - *Tầng 3*: Tích hợp API & Đặc tả NFRs (API Contracts & Performance)
   - *Tầng 4*: Quy trình Agile & Đàm phán Yêu cầu (Delivery & Collaboration)
4. **Cột mốc Chuyển giao & Kinh nghiệm Thực chiến (Delivery Milestones)**: Hành trình chuyển giao giá trị thực tế của Smart WMS và InternHub qua quy trình Agile/Scrum khép kín.
5. **Footer & Contact Hub**: Availability Badge, kênh liên hệ trực tiếp (Click-to-Copy Email, Phone/Zalo), tải Resume PDF một chạm và cam kết chuẩn mực kỹ thuật.

## 🛠️ Công Nghệ Phát Triển

- **Core**: React 19, TypeScript
- **Bundler & Tooling**: Vite 8, ESLint
- **Styling**: Tailwind CSS
- **Icons**: Lucide React + Brand SVGs

## 🚀 Khởi Chạy Local

```bash
# Cài đặt dependencies
npm install

# Khởi chạy môi trường phát triển
npm run dev

# Kiểm tra chất lượng mã nguồn
npm run lint

# Build bản release sản phẩm
npm run build
```
